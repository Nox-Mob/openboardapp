# Epic Map

The to-do list for OpenBoardApp, in the same shape as OpenCharterApp's `docs/epic.md`. Section 1 is what's left for the OpenAppHub suite migration to be "done"; the same items (S-xx) are tracked in every app. Section 2 is the product roadmap (from `roadmap.md`, which now points here). Section 3 lists known issues.

Status: ✅ done, 🟡 done with follow-ups, 🟠 partly done, ⬜ not started.
